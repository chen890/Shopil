# Shopil – הסל הכי זול 🛒

אפליקציית ווב (PWA) בעברית שמוצאת את סל הקניות הזול ביותר בסביבתכם, לפי מחירי הסופרמרקטים שמתפרסמים לפי **חוק שקיפות המחירים**.

**לאפליקציה:** https://chen890.github.io/Shopil/

## מה היא עושה

- **רשימות קניות שמורות**: כמה רשימות, הוספת מוצרים בכל רגע (חיפוש בשם, ברקוד או סריקת ברקוד במצלמה). הרשימות נשמרות במכשיר.
- **הסל הכי זול לפי מיקום**: GPS או בחירת עיר, ורדיוס חיפוש. מחשבת את מחיר הרשימה המלאה בכל סניף בטווח ומדרגת: קודם סניפים שיש בהם הכל, ואז לפי מחיר.
- **מבצעים ואמצעי תשלום**: מבצעים לכלל הלקוחות תמיד נכללים. מבצעי מועדון ומבצעי כרטיס האשראי של הרשת נכללים רק אם סימנתם שאתם חברים או מחזיקים בכרטיס.
- **הצעות כמות, אחרי ההשוואה**: לפי מבצעי "X ב־Y" בסניף הזול, הצעה להוסיף ("עוד 2 ב־₪9 בלבד") או להוריד יחידות שנשארו מחוץ למבצע ומשולמות במחיר מלא.
- **בחנות מול אונליין, מראש**: כל חישוב בודק גם סניפים קרובים וגם חנויות אונליין (כולל דמי משלוח שאתם מגדירים), ומציג סיכום: הכי זול בחנות מול הכי זול אונליין, ובכמה.
- **פירות וירקות**: פריטים כלליים כמו "עגבניות (לק״ג)", לפי המחיר הזול לק״ג בכל סניף.
- **שיתוף בוואטסאפ**: שליחת עותק של הרשימה (קישור שפותח אותה באפליקציה) ושיתוף הסניף הזול עם קישור ניווט ב־Waze.
- **שיתוף חי**: רשימה משותפת שמתעדכנת בזמן אמת אצל כל מי שפתח את הקישור, כולל סימוני ✓ וחסר (דורש הגדרת Firebase, ראו למטה).
- **קטגוריות ומצב מוצר**: הרשימה מחולקת לקטגוריות (פירות, ירקות, מוצרי חלב, משקאות, תינוקות ועוד). אפשר להוסיף, לשנות שם ולסדר קטגוריות. האפליקציה זוכרת לאיזו קטגוריה העברתם מוצר, ולומדת את סדר המחלקות מהסדר שבו אתם מסמנים מוצרים כנאספו. כל מוצר אפשר לסמן ✓ נאסף, חסר בחנות, או לערוך (כמות, הערה, החלפה, מחיקה).
- **כרטיסי הטבות**: הנחות כרטיס חבר וביחד בשבילך (אחוזים לפי פרסומים, ניתנים לעריכה).
- **מחירים מתעדכנים**: הנתונים מתעדכנים אוטומטית כל שעתיים. האפליקציה בודקת אם יש נתונים חדשים בכל שינוי ברשימה ובכל חזרה לאפליקציה, ומחשבת מחדש.

## רשתות

שופרסל, רמי לוי, יוחננוף, אושר עד, טיב טעם.

לא נכללים כרגע:
- **קרפור / יינות ביתן** ו**חצי חינם**: אתרי המחירים שלהם חוסמים גישה מחוץ לישראל, ולכן העדכון האוטומטי ב־GitHub (שרתים בחו"ל) לא מצליח להוריד אותם. הקוד תומך בהם ועובד מישראל (`pipeline/run_all.py site/data carrefour hazihinam`).
- **ויקטורי**: אתר המחירים שלה (laibcatalog.co.il) חוסם גישה אוטומטית.

## איך זה בנוי (חינם, בלי שרת)

```
GitHub Actions (כל 4 שעות)
  ├─ pipeline/fetch.py     הורדת קבצי Stores / PriceFull / PromoFull מכל רשת
  │                        (בעזרת הספרייה il-supermarket-scraper)
  ├─ pipeline/build.py     פענוח XML, פענוח מבצעים, המרה ל־JSON קומפקטי
  ├─ pipeline/geocode.py   מיקום סניפים (OpenStreetMap Nominatim, עם cache בריפו)
  └─ deploy → GitHub Pages
site/                      האפליקציה (HTML/CSS/JS סטטי), החישוב רץ בדפדפן
site/data/                 נוצר ב־CI: stores.json, catalog.json, s/<chain>-<store>.json
```

אם רשת אחת נכשלת בהורדה, נשמרים הנתונים הקודמים שלה מהאתר החי.

### הרצה מקומית

```bash
python3 -m venv .venv && .venv/bin/pip install -r pipeline/requirements.txt
.venv/bin/python pipeline/run_all.py site/data            # כל הרשתות
.venv/bin/python pipeline/run_all.py site/data tivtaam    # רשת אחת
python3 -m http.server 8765 --directory site
```

### פריסה ב־Vercel (אופציונלי)

האתר סטטי לגמרי. אפשר לחבר את הריפו ל־Vercel עם Output Directory = `site`, אבל הנתונים (`site/data`) נבנים ב־GitHub Actions ומתפרסמים ב־GitHub Pages, ולכן GitHub Pages היא הדרך הפשוטה.

## הפעלת שיתוף חי (סנכרון בין טלפונים)

שיתוף חי משתמש ב־Firebase Realtime Database (חינם בתוכנית Spark). הגדרה חד־פעמית, כ־5 דקות:

1. נכנסים ל־https://console.firebase.google.com ויוצרים פרויקט חדש (בלי Google Analytics).
2. Build → Realtime Database → Create database. בוחרים מיקום (למשל europe-west1) ו־Start in **locked mode**.
3. בלשונית Rules מדביקים את הכללים האלה ולוחצים Publish:
   ```json
   {
     "rules": {
       "lists": {
         "$id": {
           ".read": "$id.length >= 20",
           ".write": "$id.length >= 20"
         }
       }
     }
   }
   ```
   כל רשימה נשמרת תחת מזהה אקראי ארוך. מי שיש לו את הקישור יכול לקרוא ולערוך אותה, ואי אפשר לקבל רשימה של כל הרשימות.
4. Project settings → Your apps → Web (`</>`) → רושמים אפליקציה, ומעתיקים את `firebaseConfig`.
5. מדביקים את הערכים ב־`site/config.js` במקום `null`, עושים commit ו־push.

## מגבלות ידועות

- מוצרים ארוזים מושווים לפי ברקוד. פירות וירקות מושווים לפי סוג (כ־45 סוגים, למשל "עגבניות לק״ג"), לפי המחיר הזול לק״ג בכל סניף. מעדנייה ומוצרים אחרים במשקל עם קוד פנימי לא נכללים.
- מיקום הסניפים מבוסס על הכתובת שהרשת פרסמה. כשהכתובת לא נמצאה במפה, הסניף ממוקם במרכז העיר ומסומן "מיקום משוער".
- מבצעים שתלויים בסכום קנייה כולל, בקופון או בשילוב מוצרים מקבוצה לא נכללים, או נספרים לכל מוצר בנפרד.
- המחירים הם מה שהרשת פרסמה. כדאי לוודא בקופה.
